# Monolith Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pixel storm look with Monolith: monochrome black/grey/white, side-tab navigation, a rotating point-cloud figure of Mohammed in the hero, mono and Syne type, glitch transitions, crosshair cursor, halftone covers, with the same fallbacks, budgets and accessibility gates.

**Architecture:** Keep the persistent canvas, device tiers, `ViewSlot`, posters, budget script and the pointer-wind trail from plan 2. Add a `FigureCloud` points scene fed by a quantised binary generated offline from a segmented photo (photo never committed). Replace the top nav with a `Rail` (desktop) and `TabBar` (mobile). Add a `GlitchTransition` provider, a `Crosshair` cursor, `Decode` text, `Halftone` covers, scroll-driven orbit and grid floor. Remove colour from the UI.

**Tech Stack:** as plan 2 (three, @react-three/fiber, @react-three/drei, zustand, lenis, gsap, motion) plus next/font/google Syne and JetBrains Mono. Offline pipeline: Swift (Apple Vision person segmentation) and Python 3 with Pillow and numpy (already on the machine), outputs committed as a binary.

**Spec:** `docs/superpowers/specs/2026-10-31-portfolio-design.md` section 18 (supersedes 17 and section 4's top nav). Sections 8, 10, 12 still bind.

## Global Constraints

- All plan 1 and plan 2 Global Constraints still apply (branch and PR per task, self-review, no attribution trailers, exact-pinned verified dependencies, secrets scan, 44 px targets, axe zero serious/critical, no horizontal scroll at 320 px, one canvas, 3D code dynamic and client-only, fallback order reduced motion → low tier → WebGL error → static).
- Colours: only `bg #050505`, `surface #0F0F11`, `surface-2 #17171A`, `border #2A2A2E`, `muted #6B6B70`, `text #F2F2F0`, `glow #FFFFFF`. No other colour in any page. Light theme and the toggle are removed. `--accent-*` tokens stay defined but unused outside `/lab/pixel-storm` until that item is removed in Task 9.
- Fonts: Syne 800 `--font-display-src`; JetBrains Mono 400/700 `--font-mono-src` used as `font-sans` too (body is mono). Unbounded, Manrope and Silkscreen removed by the end of Task 1.
- Navigation labels exactly: HOME, WORK, LAB, ABOUT, CONTACT. Routes: `/`, `/projects`, `/lab`, `/about`, `/contact`.
- The source photo, mask and cutout live in `~/dev/portfolio/.superpowers/figure/` (git-ignored) and are never committed; only `public/figure/bust.bin` (≤ 250 KB) and `public/posters/figure.webp` (≤ 120 KB) are.
- Timings from spec 18: rotation 0.15 rad/s, scanline sweep every 4 s, glitch slice every 6 to 10 s for 120 ms, decode 24 ms/char max 900 ms, glitch wipe 200 + 200 ms, settle 1.2 s.
- Budgets: first-load ≤ 358,400 B gzip excluding 3D; 3D chunk ≤ 460,800 B; LCP ≤ 2.5 s (hard error again in Task 11); performance ≥ 0.85.

## Review Focus

1. Reduced motion: static figure poster, no canvas, no decode, no glitch, no cursor, fade transitions. Pinned in Task 4 and Task 11 e2e.
2. The rail and bottom bar must be fully keyboard operable with `aria-current`, and the tabs must never overlap content at 320 px or 1024 px. Pinned in Task 2 e2e.
3. The figure binary must fail closed: a 404 or a corrupt file shows the poster, no console error cascade. Pinned in Task 3 unit and Task 4 e2e.
4. A double click during a glitch wipe must never strand the overlay. Pinned in Task 6 e2e.
5. No colour regressions: an automated check that no rendered page contains the old accent hexes. Pinned in Task 11.

### Task 3: Figure data pipeline

**Files:**
- Create: `scripts/figure/segment.swift` (from `.superpowers/figure/segment.swift`), `scripts/figure/build-points.py`, `scripts/figure/README.md`, `public/figure/bust.bin`, `public/posters/figure.webp`, `lib/figure.ts`, `tests/unit/figure.test.ts`, `tests/fixtures/figure/tiny.bin`

**Interfaces:**
- `build-points.py <cutout.png> <out.bin> <poster.webp>`: upscales to 800 px, BFS distance-to-edge, head-aware inflation (per-row max distance, profile `sqrt(1-(1-t)^2)`, max depth 0.42 of half-width), front and back shells plus 20% sparse interior fill (no centre seam), luminance 0..255, target 56,000 points on high tier (file stores all; the loader subsamples by tier), writes `bust.bin` as little-endian records `x:int16 y:int16 z:int16 l:uint8 pad:uint8` (8 bytes, ≤ 450 KB) — NO: 250 KB cap, so store `x y z` as int8 scaled to ±127 and `l` as uint8 (4 bytes/point, 56k points = 224 KB). Header: magic `MA01`, uint32 count. Poster: 1600×1200 WebP of the front view rendered as grey squares on `#050505`, ≤ 120 KB.
- `lib/figure.ts`: `parseFigure(buffer: ArrayBuffer): { count: number; positions: Float32Array; luminance: Uint8Array }` (validates magic and length, throws `FigureFormatError` otherwise), `subsample(fig, count, seed)`, `loadFigure(url, { count })` with `fetch` + `cache: "force-cache"`; failure returns `null` (never throws to the caller).

- [ ] Unit tests with `tests/fixtures/figure/tiny.bin` (8 points): parse, reject bad magic, reject truncated, subsample determinism and count.
- [ ] Run the pipeline on `~/dev/portfolio/.superpowers/figure/cutout.png`; commit the script, README (how to regenerate; the photo is kept outside the repo), `bust.bin`, `figure.webp`. Secrets scan must pass (binary is fine).
- [ ] Commits: `feat: figure point pipeline scripts`, `feat: figure binary loader with validation`, `test: figure parser tests`, `chore: add the figure points and poster`.

### Task 4: Figure scene in the hero

**Files:**
- Create: `components/three/FigureCloud.tsx`, `components/three/shaders/figure.ts`, `components/home/HeroFigure.tsx`, `components/motion/Decode.tsx` (client), `tests/unit/decode.test.ts`, `tests/e2e/figure.spec.ts`

**Interfaces:**
- `FigureCloud({ data, count })`: `<points>` with attributes `aPos` (xyz), `aLum`, `aSeed`; uniforms `uTime uYaw uFog uScanY uGlitch(0|1) uGlitchSeed uTrail[16] uTrailDir[16] uTrailCount uRadius uWindGain uPointScale uDpr`; vertex: rotate by `uYaw` (0.15 rad/s, continuous), apply the wind trail from plan 2 Task 4 in the camera plane, glitch: three horizontal bands offset ±24 px for 120 ms when `uGlitch` is 1; point size `mix(1.5, 3.5, lum) * uDpr * uPointScale`; back-facing fade `mix(0.25, 1.0, smoothstep(-0.2, 0.2, rotatedZ))`; depth fog from camera z. Fragment: grey `lum` scaled, scanline sweep band (`abs(y - uScanY) < 0.02` → +40% brightness), square points. Demand loop at 30 fps while visible (the rotation is continuous, so the loop runs while in view; 60 fps while the trail is active); `useMarkReady` after first frame.
- `Decode({ text, as, delay })`: renders the final text in the DOM immediately (for SEO and screen readers via `aria-label`), animates a visual layer from glyph pool to text at 24 ms/char, max 900 ms; reduced motion: no animation. Pure `decodeFrame(text, progress, rng)` unit-tested.
- Hero: left column: `Decode` name in mono caps 14 px tracking 0.2em, headline in Syne, buttons; right: `ViewSlot` with the figure (poster `figure.webp`); hint; keep `data-hero-slot`.
