# Figure scripts

`segment.swift` and `build-points.py` turn one photo into the hero figure: `public/figure/bust.bin` and `public/posters/figure.webp`. They are dev tools and never run in CI. The photo never enters git.

- Steps: [How to regenerate the figure](../../docs/how-to/regenerate-the-figure.md).
- File format, build constants and limits: [Figure format reference](../../docs/reference/figure-format.md).
