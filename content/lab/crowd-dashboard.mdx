The dashboard shows how many people are in a venue right now. It has live occupancy counters, a heatmap of busy areas and a short history of the day.

When no backend is reachable, it falls back to bundled demo data. That is what you see here, so everything on the page is made up.

It talks to any backend that follows its API contract, so the same dashboard can sit on top of different counting systems. The code is on [GitHub](https://github.com/MohammedAl-Alimi/crowd_monitoring_dashboard).
